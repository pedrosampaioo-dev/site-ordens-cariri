# Instruções do Projeto

## Frontend

Para qualquer tarefa envolvendo interface (componentes, páginas, seções, estilos, layouts), aplique automaticamente os princípios e padrões da skill `frontend-design`: interfaces distintivas e de qualidade de produção, evitando estética genérica. Não é necessário que o usuário invoque `/frontend-design` explicitamente.

## Contexto de Design

Este projeto usa a skill `impeccable`. Ver `PRODUCT.md` (registro, público, princípios de design) e `DESIGN.md` (sistema visual: cores, tipografia, componentes) na raiz antes de qualquer trabalho de UI. Resumo: site institucional/cerimonial (registro `brand`) para as seis Ordens de Aperfeiçoamento Maçônico do Cariri — tradição visível, dignidade antes de conversão, sem clichês de "sociedade secreta" nem de SaaS genérico, contraste WCAG AA preservando a atmosfera ritual.
